Додаток А

Коротка пам’ятка користувача

Як запустити
Спершу відкрийте проєкт у Android Studio й дочекайтеся, поки він підтягне залежності Gradle (без інтернету це буде довго, тому ліпше щоб Wi-Fi був включений). Далі можна під'єднати телефон через USB або стартувати з емулятора. Натисніть Run (звична зелена кнопка або Shift + F10). Під час першого запуску система попросить доступ до камери і до фотографій — погодьтеся, інакше додаток не зможе нічого розпізнати.

Що вміє програма
Режим реального часу. Коли натискаєте «Сканувати через камеру», відкривається камера. Програма одразу підписує знайдений гриб і показує відсоток впевненості.
Режим фото. Кнопка «Вибрати з галереї» відкриває файловий менеджер: вибираєте знімок, модель проганяє його й видає результат.
Після кожного розпізнавання вгорі екрану з’являється назва гриба та точність у %, щоб було зрозуміло, наскільки судження впевнене.

Дрібні зручності
Програма запам’ятовує усі знайдені гриби у внутрішньому сховищі (SharedPreferences). У вкладці «Історія» можна швидко глянути, що вже зустрічалося. Якщо ж ви перейшли до галереї, потокове відео від камери одразу зупиняється щоб телефон не витрачав процесор дарма.

Що всередині
Код написаний на Kotlin у Android Studio. За камеру відповідає CameraX, модель запускається через TensorFlow Lite, саму ж модель я тренував у Teachable Machine. Дрібні дані типу історії зберігаються через стандартні SharedPreferences.

На яких телефонах працює
Додаток йде на пристроях з Android 9.0 і вище. Головне, щоби телефон мав камеру й підтримував TensorFlow Lite — більшість сучасних моделей це вміють без проблем.
